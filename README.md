# DCAR - Dual Channel Agile Receiver
The DCAR GUI application is a software based remote control intended for use with Pinnacle Technologies Dual Channel Agile Receiver. The application communicates over TCP/IP on linux or Windows operating systems using the wxWidgets portable GUI applications toolkit libraries.

Visual Studio is used to build the application for Windows, the project also contains a Windows Setup project which is used to build the DCAR.msi installer file. The wxWidgets GUI and application framework must be installed prior, visit the wxWidgets website to download and install the wxWidgets C++ development framework.

The Code::Blocks IDE is used to build the application for Linux, the project also contains a Flatpak Builder project which is used to build the installer. The wxWidgets GUI and application framework must be installed prior, visit the wxWidgets website to download and install the wxWidgets C++ development framework.
